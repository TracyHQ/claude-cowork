Northgate Industrial: the Tracy Business company site as a WordPress block theme.

== Description ==

Tracy Business is the Northgate Industrial company site packaged as a block theme. Every section of the site is a block pattern the Site Editor can edit, the look is the design's own measured token set (colours, type scale, spacing, radius) carried by theme.json, and the theme updates itself from its GitHub release.

This theme is not intended for the wordpress.org directory: it registers its own blocks and bundles patterns for a specific site.
